# Contributing to the Picco fork

This guide covers the independent Picco build described in [README.md](../../README.md).
Start with this fork's [scope](../../SCOPE.md), [roadmap](../../ROADMAP.md) and
[maintenance policy](../../GOVERNANCE.md). Todo, Pomodoro and Sudoku are intentional
features; upstream's reading-only acceptance policy does not apply to them here.

- [Getting started](getting-started.md): side-by-side checkouts and explicit Picco builds.
- [Development workflow](development-workflow.md): current checkout, verification and review.
- [Architecture](architecture.md): inherited mechanisms and downstream context.
- [Testing and debugging](testing-debugging.md).
- [Touch and UI development](touch-and-ui.md): shared UI and reference device profiles.

[AGENTS.md](../../AGENTS.md) routes agent work to the applicable engineering rules.
Inherited device descriptions are reference material, not new support or validation
commitments. The current owner request determines which work is authorized.
